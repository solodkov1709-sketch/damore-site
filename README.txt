D'Amore Hair Cosmetics — сайт (для завантаження на хостинг АБО для Claude Code)

Що всередині
  index.html   — сайт: головна, "Місія D'Amore", сторінка товару
  assets/      — усі фото та відео окремими файлами
  CLAUDE.md    — контекст проєкту для Claude Code (дизайн-система, структура,
                 що ще не доробено) — Claude Code читає цей файл автоматично

Як відкрити цю папку в Claude Code
  1. Розпакуйте архів у будь-яку папку на комп'ютері.
  2. Встановіть Claude Code (claude.com/product/claude-code), якщо ще не встановлено.
  3. У терміналі: перейдіть у цю папку (cd шлях/до/damore-site) і введіть: claude
     (або відкрийте цю папку через Claude Code Desktop / у VS Code з розширенням Claude Code).
  4. Claude Code сам прочитає CLAUDE.md і побачить поточний стан проєкту.

Як завантажити на хостинг
  Вміст цієї папки (index.html + assets) — у корінь хостингу.
  Підходить будь-який статичний хостинг: Netlify, Vercel, GitHub Pages, cPanel.
  Сервер налаштовувати не треба, переходи між сторінками через #/mission і
  #/product/moment-for-me.
